# Separating Fundamental Invariant NN PES

郝一平  [hyper@dicp.ac.cn](mailto:hyper@dicp.ac.cn)

置换不变量描述符是一种向神经网络势能面中引入置换不变性的技术。这种技术简洁而严格并且完备，可以严格的描述出神经网络势能面的置换不变性，并且保留分子构型的全部信息，适用于长程，断键，非绝热，反应性势能面等苛刻要求的场景。但是此类技术的计算成本较高，不适于大体系的计算。它向更大体系迁移的主要障碍有两个，第一个是多项式生成时间随体系规模的超线性膨胀，第二是多项式本身的数目和规模的剧烈膨胀造成的额外的拟合和推理压力。

过去社区生成置换不变量的时间正比于群的阶，而群的阶随全同原子的数量阶乘增加。新的生成算法利用图连通性判断将这个阶乘项减少到线性时间。但是生成问题的复杂度仍然在另一个层面存在。因为，单项式的数目随多项式的阶数增长的数目也极快。对于M个自变元的d阶单项式集合而言，元素个数是：

$$
\binom{M+d-1}{d}
$$

生成一个阶数为n的置换不变多项式，需要遍历这些单项式，所以，生成高阶多项式的耗时会随多项式阶数近乎指数增加，依旧是一个严峻挑战。处理这种挑战的旧方法是经验截断，仅仅使用阶数少于一个截断界限D的多项式，而截断阈值D是一个经验值，需要根据成本和拟合精度找到平衡点。

其次，多项式的数目随着键长的数目和多项式阶数快速膨胀，这一膨胀的具体公式对于计算化学社区而言还是一个谜团。但是经验来看，至少是一个高阶多项式。描述符的剧烈膨胀也剧烈的增加了神经网络的参数量，对于推理和训练（尤其是训练）造成了剧烈的压力。对于置换不变量方法而言，经验截断往往也是一个必需品。

面对这一问题，基本不变量方法被提出，它使用全体置换不变量的代数生成元代集合替置换不变量本身。这一方法简洁又有严格的数学保障。但是不幸的是，全体置换不变量的代数生成元集合的大小依然随着键长快速膨胀。膨胀的具体公式对于计算化学社区而言也是一个谜团。但是经验来看，至少也是一个高阶多项式。对于大的体系而言，基本不变量方法也需要经验截断。

更为严峻的是，基本不变量多项式本身的长度大约随原子数多项式膨胀和多项式的阶数指数膨胀。对于大体系而言，在势能面推理中计算这些巨型高阶多项式多项式的值，造成了巨大的计算压力。

我们可以通过引入可分基本不变量，来处理上述挑战。

## 可分基本不变量

可分基本不变量的出发点十分的的简单，就是对于神经网络势能面拟合而言，代数完备性是一个非常强，甚至有一点过于强的数学要求。在很多场景下，达到可分性（单射/嵌入）就足够了。

我们向读者简单的介绍什么是代数完备，什么是可分。

代数完备性是指一组不变量能够生成所有可能的不变多项式函数。换句话说，如果一组不变量是代数完备的，那么任何其他不变量都可以表示为这组不变量的多项式组合。在置换不变性的语境下，代数完备的不变量集合能够完全描述分子的所有可能的置换不变性质。

可分性（也称为单射或嵌入）是指一组不变量能够唯一地区分不同的分子构型。换句话说，如果两个分子构型具有不同的不变量值，那么它们一定是不同的构型；反之，如果两个分子构型是不同的，那么它们的不变量值也一定不同。

在神经网络势能面拟合中，我们并不需要代数完备性，因为我们只需要能够区分不同的分子构型，从而正确预测它们的能量和其他性质。可分性已经足够满足这一要求，同时可以大大减少不变量的数量和计算复杂度。我们可以简单的证明一个足够使用的结论：对于N个键长而言，使用N个置换不变的可分多项式便可以满足单射性和可分性。而且某种意义上这些多项式仅仅是关于键长的函数的一阶多项式。

我们可以用一个两个变元的体系来展示代数完备和可分。这个体系的置换群只有两个元素，代数生成元，也只有两个。

例如，考虑两个变元 $x$ 和 $y$，它们的置换群是 $S_2$，包含恒等置换和交换置换。代数完备的不变量集合可以是 $x + y$ 和 $xy$，因为任何关于 $x$ 和 $y$ 的对称多项式都可以表示为这两个基本不变量的多项式组合。

而可分不变量集合也是两个，例如只需要 $x + y$ 和 $1/x + 1/y$，或者 $x + y$ 和 $x^2 + y^2$，它们就能够唯一地区分不同的 $(x, y)$ 对，从而满足可分性要求。

## 可分不变量构造说明

我们可以寻找一系列的单变元函数，并把这些函数作用在键长上，随后把这种作用的结果作为低阶基本不变量的自变元。比如最简单的并且又理论可分性保证的函数系列是$f(x,n) = x^n$。此外经验性的选择还可以有 $f(x,n) = x^{-n}$ 或 $f(x,n) = \cos(nx)$ $f(x,n) = e^{(-x^n)}$ 等函数。

## 拟合效果

严格的数学只能保证可分多项式的对称性的严格性，和作为描述符的唯一性。对于拟合精度的效果没有任何理论保证。我们只能通过实验来验证可分多项式的拟合效果。
